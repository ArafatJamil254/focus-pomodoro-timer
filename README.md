# Pomodoro Focus Timer

Simple 25/5 pomodoro timer with an SVG circular progress ring and audio notification.

## Features
- 25m work and 5m short break sessions
- Start, pause, and reset controls
- Circular progress animation using SVG stroke dashoffset
- Browser tab title stays in sync with countdown
- Web Audio API notification beep when session ends
- Tracks completed rounds

## Run
Open `index.html` in your browser.
